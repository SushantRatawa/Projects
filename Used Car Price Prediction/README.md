#  Used Car Price Prediction

A Machine Learning project that predicts the selling price of used cars using historical vehicle data. The project focuses on data preprocessing, feature engineering, model comparison, and performance evaluation to identify the best-performing regression model.

## Features
- Data cleaning and preprocessing
- Feature engineering
- Handling categorical variables using Target Encoding
- Comparison of multiple regression models
- Used Car Price Prediction
- Model evaluation and performance comparison

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Category Encoders
- Matplotlib

## Machine Learning Concepts Used
- Data Preprocessing
- Feature Engineering
- Target Encoding
- Regression
- Train-Test Split
- Model Evaluation

## Models Implemented
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

The performance of all three models was evaluated using regression metrics.

## Dataset
Cardetails dataset
The dataset contains information about used cars, including:
- Brand
- Model
- Manufacturing Year
- Kilometers Driven
- Fuel Type
- Transmission
- Engine Capacity
- Power
- Mileage
- Torque
- Owner Type

## Project Workflow
1. Load and clean the dataset.
2. Handle missing values.
3. Perform feature engineering.
4. Encode categorical features using Target Encoding.
5. Train multiple regression models:
   - Linear Regression
   - Random Forest Regressor
   - XGBoost Regressor
6. Compare model performance.
7. Select the best-performing model.
8. Predict the selling price of used cars.

## Results
Multiple machine learning models were trained and evaluated. Random Forest Regressor achieved the best performance among the implemented models, outperforming Linear Regression and XGBoost Regressor on the test dataset.
